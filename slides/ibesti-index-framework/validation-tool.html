Validation of detected street-space transformations

This page supports the manual validation of street-space transformations detected from OpenStreetMap (OSM) data in Barcelona, Milan, and Paris.

The task is to check whether detected segments correspond to real changes in street space, using Google Street View (GSV).

What you will use

  • Validation workbook (Excel)
    Contains the sampled segments to assess, with direct GSV links.
    This is the main tool for validation.

  • Interactive maps
    Show all detected segments by type and can be used as support when needed (for example, to understand spatial context or nearby changes).
    Sampled segments are shown more prominently.

What to validate

Each row represents a single segment classified as:

  • pedestrianisation
  • living street
  • road diet
  • cycleway added

How to validate

  1. Open the Excel workbook
  2. Click the GSV link for a segment
  3. Inspect the street in GSV
  4. Use the map only if additional context is needed

Use of imagery

For each segment, compare imagery between the baseline year and the follow-up year.

  • The goal is to assess whether a change occurred between these two years, including both endpoints.
  • Start by locating imagery as close as possible to the follow-up year.
  • Then compare it with imagery as close as possible to the baseline year.

If no clear change is visible between the baseline and follow-up years:

  • check earlier imagery (before the baseline year), and
  • check later imagery (after the follow-up year)

This helps determine whether:

  • no change occurred, or
  • a change occurred, but outside the period of interest

Reference periods

  • Barcelona: baseline ~2019, follow-up ~2023
  • Milan: baseline ~2016, follow-up ~2021
  • Paris: baseline ~2020, follow-up ~2026

What to record (Excel)

For each row:

valid_change

  • yes = a change is clearly visible between the baseline and follow-up years
  • no = no such change is visible, or the detected change is clearly incorrect
  • NA = the location cannot be meaningfully assessed in GSV

unclear

  • yes = there is not enough temporal evidence to determine confidently whether the change occurred within the period of interest

comments

Use comments to note anything relevant, especially when:

  • a change is visible but happened outside the period of interest

Suggested format when a change happened outside the target period:

  • Yes change, but in Month Year

For example:

  • Yes change, but in March 2024

Validation files

Validation workbooks are shared privately with collaborators during the review phase. They will be made publicly available upon publication.
