Website Update Workflow

1.  Edit the website files (e.g. index.qmd and/or ca/index.qmd).

2.  Save the files.

3.  Preview the website:

    ./preview-site.sh

4.  Check:

    -   http://localhost:4200/
    -   http://localhost:4200/ca/

5.  If everything looks correct, stop the preview with Ctrl+C.

6.  Publish the changes:

    git status git add . git commit -m “Describe your changes” git push

Notes: - preview-site.sh renders and watches both the English and
Catalan websites. - You do not need to run quarto render manually before
pushing if you have already previewed the changes successfully.
